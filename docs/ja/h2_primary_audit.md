# H₂の一次資料監査

監査日：2026-10-15。これは**部分的な監査**です。Hirschmann et al. (2012)の
全文照合は完了していません。既存のv0.1の出典追跡項目を使い、
[契約](../../contracts/h2_solubility.yaml)と
[手動ケース](../../examples/h2_solubility/case.yaml)を更新しました。
スキーマの拡張や上流パッケージの変更は必要ありませんでした。

## 確認できたこと

| 対象 | 直接確認した資料 | 結果 |
| --- | --- | --- |
| 実装された式と単位 | 固定revisionのExoGibbsと[Seo (2024), Eq. 6][seo] | フガシティbar、圧力GPa、出力モル分率の式が一致。係数の原実験からの導出は未確認。 |
| 研究全体の総圧 | [Hirschmann (2012)の原著要旨][original] | 0.7–3 GPaはメタデータと一致。玄武岩だけの範囲や複数条件を組み合わせた適用範囲までは示さない。 |
| 実験対象 | 同じ原著要旨 | 合成玄武岩＋COHと合成安山岩＋OHは別系列。今回の溶融体組成を指定する情報ではない。 |
| 温度メタデータ | メタデータとSeoのEq. 6直前の段落 | 上限1773 Kと1723 Kの違いを確認。ただし原因は未確定。 |
| 元の温度データと経験式のフィット | Hirschmann本文を取得できず | 未確認。元の表の値や式番号を推測で補っていない。 |
| 新しい赤外吸収係数の校正 | [Chaudhari (2025)の方法・Fig. 5][calibration] | この研究自身の校正には一次資料。現行溶解度関数の物理的検証とは別。 |

原著者が書いた要旨は、そこに記載された内容については一次資料です。
所属機関のページでその要旨を読めても、未取得の実験表を読んだことにはなりません。
そのため、同じDOIについても、対象とする事実によって「確認済み」と「未確認」の
証拠項目が共存します。

## 分かったことと、まだ言えないこと

**温度上限の違いは、対象物質の違いかもしれません。**
[2025年論文のFig. 8説明][comparison]では、掲載した2012年の実験の多くは
1400 ℃で、玄武岩には1450 ℃、安山岩には1500 ℃の実験もあると記載されています。
換算すると1673.15、1723.15、1773.15 Kです。二つの上限の違いを説明できそうですが、
これはまだ推論です。この説明は2012年の実験については二次資料であり、
特定の酸化還元バッファ条件を選んだ図の説明でもあります。元の全実験表なしに、
玄武岩の適用範囲やメタデータの誤りを確定できません。
`temperature_crosscheck`から原実験へのリンクは`not_checked`を維持しました。

**一次実験にも、別の校正への依存がありました。**
2025年の研究は、ハプロ花崗岩質ガラスを使い、二つの方法から新しい赤外吸収係数
2.12 ± 0.05 L mol⁻¹ cm⁻¹を求めています。一方、同論文の過去研究の説明によれば、
2012年の研究はShelby (1994)のシリカガラスの係数0.26 L mol⁻¹ cm⁻¹を使用しています。
この古い係数の由来は、今回の監査ではまだ二次資料の記述です。候補となる古い資料を
記録しましたが、その本文は未確認、役割は`unknown`とし、確認済みの終点にはしていません。

新しい測定は、そのガラスと測定対象についての一次証拠です。ただし、同論文自体も
その係数を別組成のガラスに移す際の系統誤差を論じています。古いデータとの比較も
特定の条件を選んだものです。したがって、今回の純H₂計算に一律の補正をかける根拠には
していません。式の置き換えも行っていません。

**式の転記が合っていることと、経験式の由来が確認できることは別です。**
実装はSeoのEq. 6と一致しますが、元の実験からどう−11.403と0.76が得られたかは
まだ照合できていません。原論文の濃度の定義、単位、基準状態、温度の扱いを読む必要が
あります。今回の監査で、Seoの転記ミスが見つかったとは言えません。

## 機械可読な記録での違い

リポジトリのルートから、次のように確認できます。

```bash
python -m mceg --trace metadata_pressure contracts/h2_solubility.yaml
python -m mceg --trace metadata_temperature contracts/h2_solubility.yaml
python -m mceg --trace implementation contracts/h2_solubility.yaml
python -m mceg --trace historical_calibration contracts/h2_solubility.yaml
```

| 追跡対象 | `recorded_audit_complete` | 意味 |
| --- | --- | --- |
| `metadata_pressure` | true | 研究全体の圧力範囲の数値が原著要旨と一致する。 |
| `metadata_temperature` | false | 資料間の違いがあり、元の温度データも未照合。 |
| `implementation` | false | Seoとの式の一致まで確認。元の経験式のフィットは未確認。 |
| `historical_calibration` | false | 古い係数の由来について、直接確認した原資料まで到達していない。 |

`true`は、記録した範囲での出典照合が完了したという意味だけです。
契約の`physical_accuracy`は`unknown`のままであり、昇格しません。
ケースの9件の分類も数値結果も変わりません。EOSの外挿、溶解度の記録区間内、
証拠不足は同時に存在します。

## 取得状況と、次に必要な具体的作業

原論文のDOIは[10.1016/j.epsl.2012.06.031][doi]です。所属機関のページで
要旨を確認しました。監査当日の出版社HTML・PDFへのリクエストはHTTP 403、
出版社APIから得られたXMLは書誌情報のみで、全文指定には認証が必要でした。
著者ページやリポジトリも調べましたが、本文を取得できませんでした。
文献検索サービスの公開状況のラベルだけでは取得を確認できません。
これは今回の環境での取得結果であり、他にも入手先がないという意味ではありません。

本文を入手した後に必要なのは、次の照合です。

1. 玄武岩・安山岩の各実験について、温度、圧力、組成、フガシティ、バッファ条件を
   特定する。欠損値や除外された実験も区別する。
2. 濃度の定義、フガシティの規約、温度の扱いを含め、原論文のフィットから
   SeoのEq. 6への変換を再構成する。
3. 採用された赤外吸収係数とその出典を調べ、測定した信号、換算係数、換算後の濃度を
   分けて記録する。
4. 物理的精度の分類や数値補正を変更する前に、接続した計算全体を適切な測定と比較する。

今回、EOS側の記録は変更していません。Zhang and Duanの比較表が使ったPVTデータを
さらに元の実験までたどる作業は、別途必要です。
